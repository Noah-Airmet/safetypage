# Fixture corpus

Real, openly licensed documents, parsed far enough to exercise the document model, the anchors
and the quote checker end to end, plus two synthetic documents that stand in for the link-only
tier. Tests build a corpus database from `bundles/`.

```
sources.json   what is here: metadata, files, where each licence statement was read
sources/       the files as fetched (one is reduced, see below)
bundles/       one JSON bundle per version, generated by ../build.py; this is what tests load
```

Rebuild the bundles with `uv run --group fixtures python fixtures/build.py`. CI checks that the
committed bundles are exactly what the builder produces.

## Changes made to the sources

- `distill-zoom-in.reduced.html` is the article's HTML with embedded image data, inline SVG
  drawings, scripts and style sheets removed, which takes it from 15 MB to about 115 KB. The
  text is unchanged. The SHA-256 of the original page as fetched is recorded as the licence
  evidence hash in `sources.json`. Figures reused in the article from other sources are not
  covered by its licence, which is another reason the images are not here.
- The PDFs and the arXiv HTML files are byte-for-byte as fetched on 2026-11-10.

## No link-only documents here

Documents that are not openly licensed are never committed to this repository, including as
test fixtures. The link-only tier is tested on the two synthetic documents, which were written
for the purpose.
