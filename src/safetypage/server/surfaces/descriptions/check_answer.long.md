Audit a draft answer before you give it. Pass the answer's full text (markdown, up to 40,000 characters), with its citations as library urls or cite strings and its quotations in quotation marks or as > blockquotes.

For every citation it says whether the document, version and page exist; for every quotation, whether it is on the page cited next to it (the same verdicts as verify_quote), and which quotations have no citation at all. Fix what fails and run it again.

It checks links and quotations only. It does not check whether a page supports the claim you make about it: read the cited pages for that.
